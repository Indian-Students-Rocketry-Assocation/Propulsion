# M002 — HomiS I

| | |
|---|---|
| Date | 2025-03-11 (launch, streamed live) |
| Motor | Commercial E5, purchased from Aerosports, Vadodara |
| Design | OpenRocket (HOMIS-1 series), held by ISRA, not in this repo |
| Outcome | Launch failed |

HomiS I flew a bought motor, so there was no propellant work for this mission. No launch data or failure analysis were kept. What is above was reconstructed from team memory and ISRA's *Where We Have Been* write-up (February 2026) in September 2026.

The E5 is also the performance target for our own motor in [M003 — HomiS II](../M003-HomiSII/).
