> ### ⚠️ Potassium dichromate
> M001 used potassium dichromate as a burn-rate catalyst. We have **discontinued it and strongly urge others not to use it.** It's a hexavalent chromium compound: acutely toxic, carcinogenic, and hazardous to handle and dispose of. No later ISRA motor uses it.
